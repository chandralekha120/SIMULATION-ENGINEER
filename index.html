Project: OctoNyte – RISC-V CPU

Role: Simulation Engineer

GitHub Repository: OctoNyte – GitHub

Project Overview

The OctoNyte project involved the development and verification of a custom in-order RISC-V processor capable of issuing up to 4 instructions per cycle across 8 hardware threads. The processor was designed using Chisel, and the focus of my role was on verifying its functionality through rigorous instruction-level testing and co-simulation with the Spike ISA simulator. The project's primary goal was to validate the correctness of the processor’s implementation, including the handling of arithmetic, control flow, and memory operations.

Key Responsibilities:

  • Set up and execute co-simulation between the Spike ISA simulator and the RTL implementation.
  • Write and validate test programs for various RISC-V 32I instructions (ADDI, JAL, BEQ, etc.).
  • Develop a Python-based script to compare register states between Spike and RTL.
  • Modify the testbench to track pipeline execution cycle-by-cycle.
  • Simulate conditional branch behavior using inline assembly in C.
  • Log pre- and post-execution register states to aid debugging.
